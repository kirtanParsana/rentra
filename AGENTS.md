# RENTRA ENGINEERING RULES

## Stack

* React.js
* Vite
* Tailwind CSS
* Node.js
* Express.js
* MongoDB
* Socket.IO

## UI Philosophy

* premium minimal
* dark mode first
* smooth cinematic motion
* avoid excessive glow
* avoid over-animation
* maintain readability
* performance first

## Animation Rules

* Framer Motion for UI transitions
* GSAP only for advanced timeline/scroll work
* Lenis for smooth scrolling
* React Three Fiber only for hero sections
* avoid animating everything
* prefer subtle motion
* use GPU-friendly transforms only

## Performance Requirements

* maintain responsive UI
* avoid layout thrashing
* lazy load heavy animations
* lazy load 3D scenes
* minimize rerenders
* mobile-first responsiveness

## Code Standards

* reusable components
* modular architecture
* no duplicated logic
* avoid massive components
* preserve existing structure
* no unnecessary rewrites

## Design Standards

The UI should feel inspired by:

* Linear
* Stripe
* Framer
* Airbnb
* Apple

NOT:

* cyberpunk
* gaming UI
* neon overload
* flashy animations

## Critical Rule

Do not redesign working features unnecessarily.

Enhance incrementally.
